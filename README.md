# LLC: Lunar Lander Corporation

A 20-game challenge game  jam entry.

Controls:

- Thrust
  - Spacebar
  - A / X / South Button
- Pitch Up
  - Down
  - Back on L Stick
- Pitch Down
  - Up
  - Forward on L Stick
- Yaw Left
  - Left
- Yaw Right
  - Right
- Roll Left
  - Q
  - Left Bumper
- Roll Right
  - E
  - Right Bumper

Control camera with mouse or right stick
